プライバシーポリシー

「図解のじかん 投稿ツール」(以下「本ツール」)は、運営者が自身の TikTok アカウントに動画を投稿するために運営者本人のみが使用するソフトウェアです。

  1. 取得する情報: TikTok のログイン認可で得るアクセストークン・リフレッシュトークン、および TikTok が返すアカウントの基本情報(open_id、表示名)。
  2. 利用目的: 運営者自身のアカウントへの動画の送信と、その処理状況の確認のみ。
  3. 保存と保護: トークンは運営者の管理する PC 内にのみ保存し、第三者に提供・販売しません。外部サーバーには送りません。
  4. 第三者提供: ありません。TikTok の API との通信以外に外部送信はありません。
  5. 削除: 運営者はいつでも TikTok の「アプリと連携」設定から認可を取り消せます。取り消し後、保存済みトークンは削除します。
  6. 連絡先: 本サイトのリポジトリ GitHub Issues
  7. 改定: 内容を変えたときは本ページを更新します。最終更新 2026-10-20。

Privacy Policy

This tool ("Zukai no Jikan Posting Tool") is private software used only by its operator to post videos to the operator's own TikTok account. It stores the TikTok access and refresh tokens and the basic account information (open_id, display name) returned by TikTok's login only on the operator's own computer, and uses them solely to upload the operator's videos and check publish status. No data is shared with or sold to third parties, and nothing is sent anywhere other than TikTok's API. The operator can revoke access at any time from TikTok's connected-apps settings, after which stored tokens are deleted. Contact: GitHub Issues of this site's repository (https://github.com/harukishimizu2020-sketch/sns-shorts-automation-pages/issues). Last updated 2026-10-20.
